# 🚀 Portafolio — César Restrepo

Portafolio web personal desarrollado para presentar mi perfil profesional, habilidades técnicas, experiencia y proyectos como desarrollador **Full Stack enfocado en Backend**.

## 🌐 Demo

👉 **[Ver Portafolio en GitHub Pages](https://carc0813.github.io/Portafolio/)**

---

## 🎨 Diseño

El diseño fue desarrollado tomando como referencia un moodboard y prototipo realizado en Figma.

🔗 **[Ver diseño en Figma](https://www.figma.com/design/H0EtqsaTqYQ16kMOJ6IbGP/Portafolio---C%C3%A9sar-Restrepo?node-id=0-1&m=dev&t=kR8zBHiLZHagSnHq-1)**

### 🎯 Objetivo

Diseñar un portafolio moderno, profesional e interactivo que refleje mis habilidades como desarrollador Full Stack enfocado en Backend, transmitiendo confianza, creatividad y calidad técnica.

### 💡 Concepto

El diseño está inspirado en portafolios modernos de desarrolladores, utilizando un estilo:

- Profesional
- Moderno
- Minimalista
- Tecnológico
- Creativo
- Responsive
- Elegante
- Interactivo
